# Φ Ecosystem Intelligence R1: public project inspector

## Why this lives here
FieldConstellation is the public architectural gateway for the PhiOS family. Its existing public inventory, editorial taxonomy, source-reviewed relationship ledger and bounded HTTPS destination observations are the only default data sources. No new fleet manager is created.

## What an expanded project means
- **Platform**: PhiOS Core, Web, Mobile and XR remain pinned above ten editorial branches.
- **Inventory**: the last validated, fully paginated public GitHub snapshot, including its fetch time and metadata-update timestamp. This is not a release or CI result.
- **Source-reviewed connections**: only the existing commit/line-pinned public ledger; relationships are labeled verified-in-source or documented and carry their own scope limitations. Empty ledger coverage is **unknown**, not disconnected.
- **Public destination**: separately dated anonymous HTTPS HTML observations. Old checks are stale; never called 'live deployment' or app acceptance.
- **Installed app/CI**: explicitly unverified. A category is editorial placement, not an installed package or tested dependency.

## Optional RepoNerve R1 local handoff
The public site does **not** contact localhost, GitHub private endpoints, databases, automation agents or token-bearing services. An operator may manually choose an exact-schema public-only JSON export generated by PhiRepoNerve's companion `export-public` command. The file is never uploaded or written to localStorage. Only matching immutable IDs present in the website's independently validated **public** inventory are accepted. Unknown IDs, duplicate IDs, raw API rows, extra fields, malformed/future timestamps or mixed/private data cause an all-or-nothing rejection.

Until an operator explicitly imports such a file, the website needs no RepoNerve install or configuration and shows 'No local handoff loaded.' When the public inventory refreshes, the optional local handoff is cleared, preventing a stale private/public visibility join.

Even an accepted local handoff is **operator-provided, unauthenticated observational data**: `observedAt`, `pushedAt` and `archived` from one last complete local scan. It does not grant authority, certify CI/deployment, or identify a working integration. The matching producer schema is in `PhiRepoNerve/docs/FIELDCONSTELLATION_PUBLIC_HANDOFF.md`.

## Review gates
`npm run check`, `npm test`, `npm run build`, `npm run build:verify`, `npm run build:domain`, `npm run domain:verify`, `npm run acceptance:browser` (with Playwright installed). Verify individual project expansion, mobile narrow screen, browser-only file rejection/clear, and runtime-safe public evidence fallback. No merge, domain changes, Netlify reconfiguration or deployment without separate review.
