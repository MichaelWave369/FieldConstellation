Field Constellation meets Grok’s Field Lattice. The public repository inventory and thematic worlds now share a home with language orbits, a golden-angle spiral, activity glow, and a quick project index.

Find your way
Drag to orbit. Scroll or pinch to zoom. Right-drag or Shift-drag to pan. Press / to search. Use ↑ / ↓ outside the map to visit projects; on the map, arrow keys rotate the view. Esc clears a selection.
Five ways to explore
Constellation groups related worlds. Sphere spreads the inventory over a Fibonacci shell. Helix and Spiral follow creation dates; their threads connect consecutive creations. Orbits gives each programming language its own ring. Orbital distances and positions are artistic.
Colors and connections
Choose colors by world, language, or recent activity. Activity uses the last code push: ≤7, 8–30, 31–90, or more than 90 days ago. A subtle glow favors recent work. World links are thematic associations; orbit links join neighbors using the same language. None are verified code dependencies. Point size loosely reflects GitHub repository size.
