    Many worlds.
    One Field.

    A public observatory for the Field. Five familiar layouts now share a source-backed relationship ledger, project discovery, dated destination checks, and a doorway to the Field Atlas living library.

    Find your way
    Drag to orbit. Scroll or pinch to zoom. Right-drag or Shift-drag to pan. Press / to search. Use ↑ / ↓ outside the map to visit projects; on the map, arrow keys rotate the view. Esc clears a selection.
    Five ways to explore
    Constellation groups related worlds. Sphere spreads the inventory over a Fibonacci shell. Helix and Spiral follow creation dates; their threads connect consecutive creations. Orbits gives each programming language its own ring. Orbital distances and positions are artistic.
    Colors and connections
    Choose colors by world, language, or recent activity. Activity uses the last code push: ≤7, 8–30, 31–90, or more than 90 days ago. A subtle glow favors recent work. World links are thematic associations; orbit links join neighbors using the same language. These layout links are not code dependencies. Point size loosely reflects GitHub repository size.
    Architecture / Relationships
    The Relationships switch replaces layout links with reviewed connections on the same five layouts. Mint means verified in public source, gold means a documented contract, and optional lavender means a thematic association. Each sourced connection has commit-pinned evidence and a scope note in the inspector. Source inspection does not prove a live integration. Select a project to highlight direct neighbors while unrelated nodes dim. Links can be switched off. Coverage is deliberately bounded; no entry means not recorded.
    Guided trails
    Three handpicked visitor paths introduce public projects across the library, building tools, research and trust. Routes are editorial only, not verified dependencies. Copy a journey stop link to share or resume it; browser Back and Forward navigate visited stops. Missing or private projects are excluded from tours, and you can leave a tour at any time.
    Field Passport
    Bookmark public worlds and revisit recent discoveries in your own browser. Export/import favorites as JSON. The Passport keeps only public project IDs in local storage; browsing history is never exported or uploaded. Storage availability depends on your browser.

    Freshness
    The checked-in public snapshot works immediately. A refresh replaces it only after every API page is validated. Duplicates, private records, invalid metadata and incomplete refreshes are rejected. Failed refreshes preserve the displayed inventory. No token is required. The GitHub Pages filter follows the enabled flag, independently of destination verification.

    Coverage ledger
    Read-only reconciliation of independently dated public inventory, reviewed Atlas chapters, and Atlas-verified HTML destinations. Visitors can refresh anonymous public repository metadata or export a local audit receipt. Neither operation changes the Atlas curation or shares visitor history.
    The Atlas bridge
    The Atlas is the living library; this is the interactive map. The Atlas button opens its checked public entrance. Reviewed chapters can also be opened from a project inspector. Constellation project links use the stable public GitHub repository ID, so a name change does not create a new identity. The Atlas retains its own catalog and chapter names.
    Two builds, one continuation
    Grok’s supplied source contributed orbital and spiral formulas, its language palette, activity emphasis, quick indexing, Pages / fork filters, and expanded facts. Field Constellation contributes world categories, search, a full directory, and the perspective-correct non-WebGL renderer. Both renderers use the same layouts and color rules.
