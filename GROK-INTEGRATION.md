# Constellation × Field Lattice

This edition combines the existing Field Constellation implementation with ideas and selected formulas from the user-supplied Grok Field Lattice source. The original upload is not republished wholesale.

| Contribution | Result in this edition |
| --- | --- |
| Field Constellation thematic map | Eight worlds, search, full directory, inspector, and constellation/sphere/helix layouts |
| Grok orbital layout | One ring per language, with larger language populations on wider rings |
| Grok spiral | Golden-angle positions ordered by repository creation date |
| Grok language palette | Shared language colors in both renderers and the legend |
| Grok activity emphasis | Recent-push color lens and modest activity glow |
| Grok repository workflow | Quick index, Pages/fork filters, and expanded repository facts |
| Combined implementation | Five layouts, three lenses, two themes, one shared model and camera |

All 176 repositories from the supplied public reference snapshot were reconciled with the connected public inventory during integration. The export was refreshed from the public GitHub endpoint and now includes FieldConstellation itself. The integration counters record that original reconciliation, rather than a promise that all future inventories have the same membership.

The browser uses bundled Three.js and OrbitControls. When WebGL is unavailable, Canvas projects the same scene positions with the same perspective camera; it does not replace the model with a flat independent diagram. Chronological links follow actual creation order. Thematic proximity remains an editorial visualization, not evidence of code dependencies.

The public export contains public repository records and no authentication material. It can be hosted as static files under a GitHub Pages subpath.
